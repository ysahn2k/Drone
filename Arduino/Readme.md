# Arduino Drone

## GY-87 센서 정리 (ESP32-S3-DevKitC-1, I2C)

요청하신 대로 센서 기능을 아래 3개로 나눠서 정리했습니다.

1. **IMU (자세 제어용)**: `MPU6050`
   - 가속도(AX/AY/AZ), 자이로(GX/GY/GZ)를 읽음
   - 예제에서는 ±2g, ±250dps 기본 스케일 사용

2. **지자계(Heading/Yaw 보정용)**: `HMC5883L`
   - X/Y/Z 자기장 데이터를 읽음
   - 연속 측정 모드 및 기본 게인(1.3Ga) 사용

3. **기압계(고도 추정용)**: `BMP180`
   - 온도/기압 값을 읽음
   - 내부 보정 계수를 읽고 Bosch 보정 식으로 계산

## 단일 파일 예제

- 파일: `Arduino/GY87_AllInOne.ino`
- 목적: GY-87의 MPU6050/HMC5883L/BMP180을 하나의 스케치에서 초기화하고 주기적으로 읽어서 시리얼 출력

### 핀/배선
- 기본 예제 핀: `SDA=8`, `SCL=9`
- 실제 연결 핀에 맞게 코드 상단 상수(`SDA_PIN`, `SCL_PIN`)를 변경하세요.

### I2C 주소
- MPU6050: `0x68`
- HMC5883L: `0x1E`
- BMP180: `0x77`

## 참고

현재 작업 환경에서는 `madflight.com`에 직접 접속이 되지 않아(HTTP 403) 사이트 본문 인용은 포함하지 못했습니다.
코드는 GY-87의 각 센서를 독립적으로 확인/디버깅할 수 있도록 Arduino 단일 파일 예제로 구성했습니다.

madflight 라이브러리 API 기준 코드로 완전히 맞추려면, 사용 중인 madflight 문서의 해당 페이지 링크/예제 코드를 주시면 그 내용만 반영해 다시 정리하겠습니다.
